# Simple Interest Calculator

A simple command-line tool to calculate the interest earned or paid on a loan or investment based on a fixed percentage of the principal amount.

## 📝 Project Overview
This repository contains a simple interest calculator. Unlike compound interest, simple interest is calculated only on the initial amount (principal) that you invest or borrow, making it a fundamental tool for basic financial planning.

## 🔢 Mathematical Formula
The application uses the standard financial formula to determine the interest:

$$I = P \times r \times t$$

**Where:**
* **$I$**: **Interest** (The total interest amount)
* **$P$**: **Principal** (The initial amount of money)
* **$r$**: **Rate** (The annual interest rate)
* **$t$**: **Time** (The time period in years)

To calculate the total amount (Principal + Interest):
$$A = P + (P \times r \times t)$$

## 🚀 Features
* **Bash Script**: Run calculations directly in your Linux/Unix terminal or Git Bash.
* **Python Script**: A cross-platform script for users with Python installed.
* **User Input**: Interactive prompts for Principal, Interest Rate, and Time.
