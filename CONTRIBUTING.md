# Contributing to Simple Interest Calculator

First off, thank you for considering contributing to this project! It’s people like you that make the open-source community such an amazing place to learn, inspire, and create.

## How Can I Contribute?

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

### 1. Reporting Bugs
If you find a bug, please create an **Issue** in the repository. Include:
* A clear and descriptive title.
* Steps to reproduce the bug.
* What you expected to happen vs what actually happened.

### 2. Suggesting Enhancements
If you have an idea to make the calculator better (e.g., adding compound interest features or a web interface):
* Open an **Issue** with the tag "enhancement".
* Explain why this feature would be useful.

### 3. Documentation Improvements
If you find a typo or think the README could be clearer, feel free to submit a **Pull Request** directly.

### 4. Code Contributions
To contribute code:
1. **Fork** the repository.
2. Create a new branch (`git checkout -b feature/AmazingFeature`).
3. Commit your changes (`git commit -m 'Add some AmazingFeature'`).
4. Push to the branch (`git push origin feature/AmazingFeature`).
5. Open a **Pull Request**.

## Style Guidelines
* Keep the code clean and follow Python's PEP 8 style guide.
* Ensure your comments and documentation are in English.
* Test your changes before submitting.

## Join Us!
We look forward to your contributions. Happy coding!
